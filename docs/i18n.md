# Système de Traduction Centralisé (i18n) — TRACKING

## 1. Vue d'ensemble de l'architecture

Le système d'internationalisation de l'application **TRACKING** a été conçu pour respecter l'architecture PHP procédurale/SiteGround existante (*« Aucune architecture en 3 couches »*). Il centralise l'ensemble des libellés dans des dictionnaires structurés et offre des fonctions de traduction contextuelles avec repli automatique (*fallback*) vers le français (`fr`).

### Langues supportées
- **Français (`fr`)** — Langue par défaut et source de vérité
- **Anglais (`en`)**
- **Allemand (`de`)**
- **Néerlandais (`nl`)**

## 3. Détermination de la langue active

L'ordre de priorité pour déterminer la langue est le suivant :
1. **Paramètre URL `?lang=code`** : Permet le changement explicite via le sélecteur. Met à jour immédiatement la session et un cookie d'un an (`app_lang`).
2. **Session PHP `$_SESSION['lang']`** : Conserve la préférence durant la navigation.
3. **Cookie `$_COOKIE['app_lang']`** : Mémorise le choix du visiteur pour ses visites ultérieures.
4. **En-tête `Accept-Language` du navigateur** : Détecte automatiquement la langue préférée de l'utilisateur.
5. **Défaut** : Français (`fr`).

## 4. Fonctions d'aide (Helpers)

Toutes les fonctions sont déclarées dans `api/lib/i18n.php` et disponibles globalement :

| Fonction | Description | Exemple |
|---|---|---|
| `__($key, $params = [])` | Traduit une clé avec interpolation facultative de paramètres. | `__('shipments.results_count', ['count' => 5])` |
| `_e($key, $params = [])` | Échappe (`htmlspecialchars`) et affiche directement la chaîne traduite. | `_e('common.save')` |
| `__attr($key, $params = [])` | Prépare une chaîne pour un attribut HTML (`placeholder`, `title`, `value`). | `<input placeholder="<?= __attr('common.search') ?>">` |
| `__js($key, $params = [])` | Prépare une chaîne sécurisée pour JavaScript. | `alert('<?= __js('common.confirm') ?>');` |
| `format_localized_date($date, $format)` | Formate une date avec les mois et les connecteurs dans la langue courante. | `14/10/2026 à 17:30` (FR) / `14/10/2026 at 17:30` (EN) |
| `render_flag_svg($countryOrCode, $class)` | Génère le SVG vectoriel autonome et homogène d'un drapeau (FR, GB/EN, DE, NL, BE, etc.). | `<?= render_flag_svg('fr') ?>` |
| `render_language_switcher($theme)` | Génère le composant de sélection de langue avec drapeaux SVG, flèche animée et persistance. | `<?= render_language_switcher('dark') ?>` |
| `render_phone_input_field($name, $val, $err)` | Génère le champ téléphone international avec sélecteur d'indicatif (drapeaux pays réels et codes +33, +32...). | `<?= render_phone_input_field('recipient_phone', $val) ?>` |
| `render_i18n_js_translations()` | Injecte le dictionnaire JavaScript dans `window.I18N`. | Inclus dans `templates/head.php` et `admin_header.php` |

### Règles d'interpolation
Pour les chaînes variables, utilisez les syntaxes `:nom` ou `{nom}` dans les dictionnaires.
Exemple :
```php
// Dictionnaire : 'dashboard.welcome' => 'Bienvenue, :name !'
echo __('dashboard.welcome', ['name' => 'Alice']); // Affiche "Bienvenue, Alice !"
```

## 5. Comment ajouter une nouvelle clé de traduction

1. Ouvrir `lang/fr.php` et ajouter la clé avec un préfixe logique :
   ```php
   'invoices.title' => 'Factures d\'expédition',
   ```
2. Ouvrir les autres dictionnaires (`lang/en.php`, `lang/de.php`, `lang/nl.php`) et y ajouter **exactement la même clé** :
   ```php
   // lang/en.php
   'invoices.title' => 'Shipping Invoices',

   // lang/de.php
   'invoices.title' => 'Versandrechnungen',

   // lang/nl.php
   'invoices.title' => 'Verzendfacturen',
   ```
3. Lancer l'outil d'audit pour vérifier la parité :
   ```bash
   php scripts/check-i18n.php
   ```

## 6. Comment ajouter une nouvelle langue

1. Dans `api/lib/i18n.php` :
   - Ajouter le code langue (ex: `'es'`) dans la constante `SUPPORTED_LANGUAGES`.
   - Ajouter la configuration dans `get_available_languages()` :
     ```php
     'es' => ['code' => 'es', 'label' => 'Español', 'native' => 'Español', 'flag' => '🇪🇸', 'locale' => 'es_ES'],
     ```
   - Ajouter les noms de mois et connecteurs dans `format_localized_date()`.
2. Créer le fichier `lang/es.php` en dupliquant `lang/fr.php` et en traduisant les valeurs.
3. Lancer `php scripts/check-i18n.php` pour valider que 100% des clés sont présentes et non vides.

## 7. Outils de contrôle qualité

- **Audit des dictionnaires et couverture du code** :
  ```bash
  php scripts/check-i18n.php
  ```
  Vérifie l'égalité du nombre de clés, l'absence de chaînes vides, et contrôle que toutes les clés appelées dans les templates PHP existent dans `lang/fr.php`.

- **Test de rendu multi-langues** :
  ```bash
  php scripts/test-render-pages.php
  ```
  Simule la génération des éléments clés (navigation, dates, badges de statut, modes de transport, e-mails de notification) dans les 4 langues.
